# 排行榜改版：参考 Match Day App 的简洁 Leaderboard

参考图里的排行榜是「一行一张卡」：左边名次数字，接着圆形头像，中间球员名字 + 一行小字副信息，右边一个醒目的积分数字。没有任何长条进度条。目前桌面版最右边那条占 44% 宽度的长条是「空白感」和视觉怪异的主因。

## 目标

桌面与手机采用同一套语言，去掉长条，把积分做成右侧的大号数字。

## 桌面版（DesktopRankingTable）

- 移除积分长条（含 MAX 徽章与 `animate-bar-grow` 填充），改为右侧大号积分数字 + 下方小写 `积分` 标签。
- 列宽收窄成：名次 / 球员（含头像与副信息）/ 出赛 / 冠军 / 积分，积分列只占约 14%，整表宽度用 `max-w-3xl` 居中，消除中间大片空白。
- 球员单元格改成「圆形头像 + 名字 + 副信息小字（出赛 · 冠军 · 胜率）」，名次用斜体大数字，前三名保留金/蓝/银强调色与徽章。
- 每行改为独立卡片式：行间 8px 间隙、圆角、hover 时轻微上移与阴影；去掉前三名后的渐变分隔行。
- 表头保留现有深色条，但精简为四个标签，与数据列对齐。

## 手机版（MobileRankingCard）

- 顶层行去掉细进度条，改为名次 + 圆形头像 + 名字 + 副信息小字，右侧大号积分。
- 展开区保留胜率/场均等微型数据面板，去掉重复的头像块（头像已移到主行），触控目标维持 48px 以上。

## 保持不变

排名计算逻辑、数据获取、RankDelta 升降指示、头像点击放大、语言切换与所有后端逻辑均不改动，仅调整展示层。

## 技术要点

- 只改 `src/components/DesktopRankingTable.tsx`、`src/components/MobileRankingCard.tsx`，必要时微调 `src/pages/RankingPage.tsx` 的容器宽度与骨架屏，使其与新行高一致。
- 副信息文案复用 `t.ranking` 现有词条与 `src/lib/ranking-display.ts` 的 `getWinRate` / `getAveragePoints`。
- 颜色全部走现有语义 token（accent / primary / muted-foreground），不写死颜色。
- 改完在桌面 1657px 与手机宽度各截图核对。
